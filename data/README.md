
# Dataset Information

This project uses the Online Retail II dataset from the UCI Machine Learning Repository.

**Dataset Source:** https://archive.ics.uci.edu/dataset/502/online+retail+ii

Download the original Excel workbook and place it in this folder before running the analysis notebook.

The original dataset is not included in this repository because of its large file size.

Dataset period: December 2009 – December 2011.
